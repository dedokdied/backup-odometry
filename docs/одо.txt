**Вопрос (Алексей):**
Если в пакете ROS2 запрещён входной топик с данными ГНСС, откуда он узнает начальное положение, чтобы выдавать текущие координаты?

**Ответ:**
Запрета нет. В описании задачи **допускается** использование следующих топиков:
*   `/sensing/gnss/master/fix` — позиция по GNSS (master)
*   `/sensing/gnss/master/vel` — скорость по GNSS (master)
*   `/sensing/gnss/rover/fix` — позиция по GNSS (rover)
*   `/sensing/gnss/rover/vel` — скорость по GNSS (rover)
